# 日経225構成銘柄データについて

日経225の構成銘柄は日本経済新聞社が算出しており、機械可読な公式API/CSVは
提供されていません。以下の手順で手動データを用意し、取り込んでください。

## 手順

1. 「日経平均プロフィル」の構成銘柄一覧ページ
   （https://www.nikkei.com/marketdata/quote/NK225/constituents/）を開く
2. 掲載されている225銘柄の「証券コード」「銘柄名」「業種」を
   `nikkei225.template.csv` と同じフォーマット（`symbol,name,sector`）で
   CSVにまとめる（コピー＆ペースト → 表計算ソフトで整形 → CSV書き出し、が簡単）
3. できあがったCSVの中身を、管理画面の「日経225更新」フォームに貼り付けて送信
   （内部的には `POST /api/admin/import-nikkei225` に `{ csv: "<CSV文字列>" }` を送信）
4. 件数が225件でない場合は警告が返るので、入れ替え時期でないか・
   データの過不足がないか確認する

## 更新タイミング

日経225の定期入れ替えは例年4月・10月頃（臨時入れ替えが入ることもある）。
入れ替えが発表され、日経平均プロフィル側の情報が更新され次第、
同じ手順で再取り込みする（`replaceNikkei225` が既存データを洗い替える）。
